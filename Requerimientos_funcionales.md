# Requerimientos funcionales principales de PETCARD

## Usuario

- **RF-01.** El sistema debe permitir al Usuario registrarse, iniciar y cerrar sesión, recuperar su contraseña y gestionar sus datos de perfil.
- **RF-02.** El Usuario debe poder registrar, consultar, editar y eliminar sus mascotas, y consultar la ficha de cada una.
- **RF-03.** El Usuario debe poder consultar el carnet de vacunas y los planes de alimentación de sus mascotas.
- **RF-04.** El Usuario debe poder consultar los servicios disponibles y solicitar, consultar o cancelar citas para sus mascotas.
- **RF-05.** El sistema debe mostrar la disponibilidad de horarios al solicitar o reprogramar una cita.
- **RF-06.** El Usuario debe poder consultar sus notificaciones y marcar como leídas las que ya revisó.

## Veterinario

- **RF-07.** El Veterinario debe poder consultar su agenda, las citas asignadas y la información de las mascotas que atenderá.
- **RF-08.** El Veterinario debe poder registrar observaciones de atención, vacunas aplicadas y planes de alimentación para las mascotas.

## Administrador

- **RF-09.** El Administrador debe poder gestionar las cuentas de Usuario, Veterinario y Administrador.
- **RF-10.** El Administrador debe poder gestionar mascotas y el catálogo de servicios.
- **RF-11.** El Administrador debe poder crear, consultar, reprogramar, cancelar y actualizar el estado de las citas.
- **RF-12.** El Administrador debe poder gestionar los registros de vacunas, planes de alimentación y notificaciones.
- **RF-13.** El Administrador debe poder consultar información general del sistema y reportes disponibles.

## Funciones automáticas

- **RF-14.** El sistema debe enviar confirmaciones y recordatorios de citas y vacunas por los canales habilitados.
- **RF-15.** El sistema debe relacionar las cuentas con sus roles y limitar el acceso a la información según los permisos correspondientes.
