# 🐾 PetCard

**Plataforma digital para la gestión de mascotas y servicios veterinarios.**

## Sobre el proyecto

PetCard centraliza en un solo lugar la información de salud y cuidado de las mascotas. Permite a los dueños llevar el control de sus animales, a los veterinarios gestionar sus citas y atenciones, y a los administradores supervisar todo el sistema.

Con PetCard se elimina la dependencia de carnets de vacunas en papel, se mejora el seguimiento de cada mascota y se facilita la comunicación entre dueños y clínicas veterinarias.

## Qué ofrece

### Para los dueños de mascotas
- Registro y gestión de sus mascotas, con foto
- Agendamiento de citas veterinarias
- Carnet digital de vacunas
- Planes de alimentación personalizados
- Notificaciones y recordatorios

### Para los veterinarios
- Panel con estadísticas de citas
- Confirmación de citas
- Registro de observaciones clínicas
- Creación de planes nutricionales para las mascotas atendidas

### Para los administradores
- Panel de control general del sistema
- Gestión de usuarios, mascotas, citas, vacunas, servicios y planes de alimentación
- Gestión de notificaciones

## Tecnologías utilizadas

| Área | Tecnología |
| --- | --- |
| Frontend | HTML, CSS y JavaScript |
